# 🎨 Meme Generator App

A simple React app that generates random meme images and allows users to add custom top and bottom text.

## 🚀 Features
- Fetches random memes from API
- Add custom top and bottom text
- Responsive design
- Simple and clean UI

## 🛠️ Tech Stack
- React JS
- JavaScript
- CSS
- Imgflip API

## 📸 How it works
1. Click "Get a new meme image"
2. Random meme image is loaded
3. Add your own top and bottom text
4. Create funny memes instantly 😂

## 📦 Installation

```bash
git clone https://github.com/ChadubulaVani/meme-generator
cd meme-generator
npm install
npm start
